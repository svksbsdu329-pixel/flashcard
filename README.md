# 카드한장

선생님과 학생이 어느 과목에서든 사용할 수 있는 플래시카드 웹 앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도 설치나 서버가 필요하지 않습니다.

## 주요 기능

- 과목 생성, 수정, 삭제
- 플래시카드 생성, 수정, 삭제, 과목 이동
- 전체 카드 검색과 즐겨찾기
- 무작위 학습, 힌트, 키보드 조작, 암기 상태 기록
- 학습 결과와 주간 학습량 표시
- 브라우저 자동 저장
- JSON 파일로 전체 자료 백업 및 복원

데이터는 사용 중인 브라우저의 로컬 저장소에 보관됩니다. 다른 기기로 옮길 때는 설정의 내보내기/가져오기를 사용하세요.
